# hardware-support-team — demo data

Fake data for the `hardware-support-team` catalog namespace: customer support at
**Voltaris Hardware**, a fictional B2B vendor of servers, storage, networking and endpoints.
Every company, person, email address and number here is invented.

## Files

| Workspace (`workspace_id`) | Agent | Files |
|---|---|---|
| `hardware-support-customer-db` | @CustomerEngagementAssistant | clients.csv (5), contacts.csv (10), tickets.csv (12), emails.md (16), account_notes.md |
| `hardware-support-orders-db` | @OrderManager | orders.csv (10), order_lines.csv |
| `hardware-support-stock-db` | @StockManager (read/write) | stock.csv (20 SKUs), stock_movements.csv |
| `hardware-support-products-db` | @ProductExpert | products.md (20 SKUs) |
| `hardware-support-sales-db` | @SalesAssistant | price_list.csv, pricing_policy.md |
| `hardware-support-contracts-db` | @ContractingAssistant | contracts.csv (6), terms_and_conditions.md |

All of it is generated by `scripts/build_hardware_support_team.py` from one set of records,
so it stays consistent: stock `reserved` equals the open order lines, and every order's unit
price is the list price less the contract discount in force on the order date. The script
also rebuilds `data/catalog-import/catalog.hardware-support-team.yaml` from
`catalog.template.yaml` (edit prompts in the template, never in the generated bundle).

```bash
uv run python scripts/build_hardware_support_team.py
curl -s -X POST http://localhost:8000/admin/catalog/namespace/import \
  -H "Content-Type: application/yaml" \
  --data-binary @data/catalog-import/catalog.hardware-support-team.yaml
```

## Resetting stock after a demo

Workspace seeding never overwrites an existing file, so stock changes made by
@StockManager persist across teams. To start clean, delete the two files and create a new team:

```bash
rm workspaces/anonymous/_id/hardware-support-stock-db/stock*.csv
```

The same applies to the other workspaces if you change their data: delete the old files so
the new team re-seeds them.
